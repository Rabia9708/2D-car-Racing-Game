# 2D-car-Racing-Game
A simple 2D Car Racing Game developed in C++ as a university project. The game allows players to control a car, avoid obstacles and other vehicles,
and achieve the highest possible score.
## Team Members
-RABIA IZHAR
-AREEJ ZEHRA
-NOOR-UL-HUDA

## How to Run
1. Clone this repository
2. Open the project in Visual Studio
3. Build and run
4. you must install raylib to run this game 
5. ## Features
- Control a car with the keyboard
- Avoid obstacles and other vehicles
- Score system

## Controls
- Arrow keys: move the car
